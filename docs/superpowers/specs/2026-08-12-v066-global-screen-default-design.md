# GameFold PC V0.6.6 全局屏幕默认值统一设计

## 目标

将“高级设置 → 模拟设置 → 修改默认配置”中的屏幕大小默认值从 `1280x720` 统一为 `1067x600`，同时保留 V0.6.6 RC2 已验证的游戏启动、GTA 全屏、LSFG-VK、控制器和快捷菜单行为。

## 数据边界

- 全局默认配置由 `PrefManager.screenSize` 提供，只影响今后创建的新游戏容器。
- 已有游戏容器各自保存的 `container.screenSize` 不参与本次迁移，也不被修改。
- 首次运行新版本时执行一次独立的全局屏幕默认值迁移：缺省值或历史默认值 `1280x720` 改为 `1067x600`；其他用户自定义值保持不变。
- 迁移使用独立版本键，完成后不再重复执行，因此用户之后手动选择 `1280x720` 或其他值不会被再次覆盖。

## 验证

- 单元测试覆盖缺省值、历史默认值、自定义值和已经迁移四种状态。
- 完整 Legacy 离线回归必须通过。
- 构建 `versionName=0.6.6`、新 `versionCode` 的候选 APK，原位覆盖安装，不卸载、不清数据和文件权限。
- 真机核对“修改默认配置”显示 `1067x600`；用户验收后将同一字节 APK 冻结为 V0.6.6 基线。
