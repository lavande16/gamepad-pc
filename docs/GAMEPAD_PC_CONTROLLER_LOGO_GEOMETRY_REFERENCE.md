# GamePad PC 手柄与 Logo 几何参数参考

本文记录两个已归档版本在三种横屏分辨率下的手柄与 logo 参数，供后续应用复用。

- `V2.3 / 10028`：`releases/baselines/GamePad-PC-V2.3/GamePad-PC-V2.3-EMPTY-HOME-10028.apk`
- `V2.4 / 10033`：`releases/baselines/GamePad-PC-V2.4-10033/GamePad-PC-V2.4-2304X1296-10033.apk`
- 参数来源：`V2.3 / 10028` 源码提交 `dc52f628550104b315d18719f4c026bb6c6207ee`；`V2.4 / 10033` 源码提交 `958a3414ad9fe445c24518bfba6d62ab5d1a36eb`
- 单位均为屏幕像素（px）；坐标原点在左上角，位置均为绘制矩形左上角。

## 1. 设计坐标与绘制层级

设计画布固定为 `2304×1440`。下方手柄先应用左右两组手柄变换，再应用分辨率 viewport 变换；logo 只应用 home/logo viewport 变换。

### 下方手柄的公共设计参数

以下参数在 `10028` 与 `10033` 间保持不变：

| 元素 | 左组设计坐标/尺寸 | 右组设计坐标/尺寸 |
|---|---:|---:|
| 十字键 | `(130, 1311)`, `706×706` | `(1644, 1311)`, `706×706` |
| 摇杆帽 | `(307.5, 1488.5)`, `351×351` | `(1821.5, 1488.5)`, `351×351` |
| 肩键 ZL / R | `(93, 1277)`, `138×138` | `(1608, 1277)`, `138×138` |
| 肩键 L / ZR | `(734, 1277)`, `138×138` | `(2249, 1277)`, `138×138` |
| 下方 − / + | `(734, 1912)`, `138×138` | `(1608, 1912)`, `138×138` |

左右手柄组变换：

| 组 | scale | translateX | translateY |
|---|---:|---:|---:|
| 左组 | `0.72` | `19.04` | `-115` |
| 右组 | `0.72` | `499.36` | `-115` |

因此，手柄元素的公共组内尺寸为设计尺寸乘 `0.72`。例如十字键为 `508.32×508.32`，摇杆帽为 `252.72×252.72`。

### Logo 公共设计参数

GamePad logo 的设计矩形为：`(1978, 56)`, `270×77`。它不经过左右手柄组变换。

## 2. 各分辨率的 viewport 变换

### `V2.3 / 10028`

`10028` 尚未对 `2304×1296` 做专用 1:1 规则，因此该档位走通用居中缩放：`scale=0.9, translateX=115.2, translateY=0`。

| 实际分辨率 | 下方手柄 viewport | Logo/home viewport |
|---|---|---|
| `2304×1440` 全屏 | `scale=1, X=0, Y=0` | `scale=1, X=0, Y=0` |
| `1920×1080`（1080P，16:9） | `scale=0.82, X=16, Y=-44` | `scale=0.75, X=144, Y=0` |
| `2304×1296`（16:9） | `scale=0.9, X=115.2, Y=0` | `scale=0.9, X=115.2, Y=0` |

### `V2.4 / 10033`

`10033` 保持 1:1 手柄尺寸；`2304×1296` 下只将下方手柄上移 72px，logo 单独回到原生 Y 原点。

| 实际分辨率 | 下方手柄 viewport | Logo/home viewport |
|---|---|---|
| `2304×1440` 全屏 | `scale=1, X=0, Y=0` | `scale=1, X=0, Y=0` |
| `1920×1080`（1080P，16:9） | `scale=0.82, X=16, Y=-44` | `scale=0.75, X=144, Y=0` |
| `2304×1296`（16:9） | `scale=1, X=0, Y=-72` | `scale=1, X=0, Y=0` |

## 4. 复用公式与版本差异

对下方手柄元素，先应用组变换，再应用 viewport：

```text
x_screen = viewportScale × (groupScale × x_design + groupTranslateX) + viewportTranslateX
y_screen = viewportScale × (groupScale × y_design + groupTranslateY) + viewportTranslateY
width_screen  = viewportScale × groupScale × width_design
height_screen = viewportScale × groupScale × height_design
```

Logo 不经过左右组变换：

```text
x_screen = viewportScale × x_design + viewportTranslateX
y_screen = viewportScale × y_design + viewportTranslateY
size_screen = viewportScale × designSize
```

关键差异：

- `10028` 的 `2304×1296` 是 `0.9` 倍缩放，手柄与 logo 都缩小并居中。
- `10033` 的 `2304×1296` 手柄与 `2304×1440` 保持完全相同的尺寸和 X 坐标，仅下方手柄 Y 方向上移 72px；logo 保持全屏时的尺寸和位置。
- 两个版本的 `1080P` 规则相同：下方手柄 `0.82 / (16,-44)`，logo `0.75 / (144,0)`。
