# 游戏启动页固定提示文案清单

GameFold PC V0.6.6 不再在游戏启动页显示以下轮播固定提示；动态启动状态和进度文案继续保留，不属于本清单。

以下文案继续集中保留，便于审计或后续重写。`%s` 为运行时插入的菜单名称。

| Key | Simplified Chinese | English |
| --- | --- | --- |
| `game_launch_tip_1` | 首次启动可能需要几分钟时间 | Booting may take a few minutes on first launch |
| `game_launch_tip_2` | 提示：你可以在游戏设置中点击“%s”来查看游戏文件。 | Tip: You can view the game files by pressing “%s” in the game settings. |
| `game_launch_tip_3` | 提示：你可以前往主设置菜单下载自定义驱动，用于 Bionic 容器。 | Tip: You can go to the main settings menu and download custom drivers for your device to be used on Bionic. |
| `game_launch_tip_4` | 提示：如果遇到 DirectX 错误，请尝试在 Bionic 上使用 DXVK 1.11.1-sarek 和 System driver。 | Tip: If you are getting a DirectX error, try using DXVK 1.11.1-sarek and System driver on Bionic. |
| `game_launch_tip_5` | 提示：如果游戏无法启动，请检查设置齿轮下的“%s”——你应该会看到一个旋转的立方体。 | Tip: If games aren't booting for you, check “%s” under the settings cog - you should see a spinning cube. |
| `game_launch_tip_6` | 提示：DirectX 8/9/10/11 游戏使用 DXVK，DirectX 12 游戏使用 VKD3D。 | Tip: Use DXVK for DirectX 8/9/10/11 games and VKD3D for DirectX 12 games. |
| `game_launch_tip_7` | 提示：使用 Turnip 驱动来运行 DirectX 12 游戏。不支持 Turnip 的设备对 DirectX 12 的支持目前有限。 | Tip: Use Turnip drivers to play DirectX 12 games. DirectX 12 support for devices that don't support Turnip is currently limited. |
| `game_launch_tip_8` | 提示：如果控制器无法使用，请启用 Steam Input 并检查你的应用是否未安装到隐私空间。 | Tip: If controls don't work, enable Steam Input and check that your app isn't installed to a private space. |
| `game_launch_tip_9` | 提示：要向游戏添加文件，请将它们放入设备的 Downloads 文件夹，点击“%s”，它们就会出现在 D: drive 中。 | Tip: To add files to the game, place them in your device's Downloads folder, hit “%s” and they will be in D: drive. |
| `game_launch_tip_10` | 提示：如果游戏无法运行，可从 gamenative.app/compatibility 导入适用于你的 GPU 或 GPU 系列的配置。 | Tip: Import a config from gamenative.app/compatibility for your GPU or GPU family if you can't get your game working. |
| `game_launch_tip_11` | 提示：在游戏中使用快捷菜单的性能 HUD 查看 FPS 统计信息。 | Tip: Use the quick menu performance HUD when you want FPS stats in-game. |
| `game_launch_tip_12` | 提示：如果游戏没有声音，请使用 Proton 10 自动提取 XAudio DLLs。 | Tip: If your game has no audio, use Proton 10 to automatically extract XAudio DLLs. |
| `game_launch_tip_13` | 提示：你可以通过设备的返回键启用或禁用屏幕手柄。 | Tip: You can enable or disable the onscreen controller with your device's back key. |
| `game_launch_tip_14` | 提示：你可以通过设备的返回键调出键盘。 | Tip: You can bring up the keyboard with your device's back key. |
| `game_launch_tip_15` | 提示：在容器中用双指点击可以模拟鼠标右键。 | Tip: You can tap with two fingers inside the container to right click. |
| `game_launch_tip_16` | 提示：使用屏幕手柄时，可以禁用鼠标以防止误触。 | Tip: If you are using the onscreen controller, you can disable the mouse to prevent accidental touches. |
| `game_launch_tip_17` | 提示：在 Discord 上报告问题，以便我们修复。 | Tip: Report issues on Discord so we can fix them. |
| `game_launch_tip_18` | 提示：如果你使用的是 8 Elite 设备，请使用 Turnip Gen8 V25/V30 或 MrPurple T26 驱动。 | Tip: Use the Turnip Gen8 V25/V30 or MrPurple T26 driver if you are on an 8 Elite device. |
| `game_launch_tip_19` | 提示：在游戏中通过快捷菜单降低分辨率并使用 FSR 可以提升性能。 | Tip: Lower resolution and use FSR from the quick menu in-game to boost performance. |
| `game_launch_tip_20` | 提示：如果加载游戏后整个应用都崩溃，说明你的设备 RAM 不足。 | Tip: If the entire app is crashing after loading a game, your device is running out of RAM. |
| `game_launch_tip_21` | 提示：尝试使用 SurfaceFlinger 渲染器以提升 FPS 和降低延迟。 | Tip: Try the SurfaceFlinger renderer to improve FPS and latency. |
| `game_launch_tip_22` | 提示：你可以启用触屏模式。 | Tip: You can enable touchscreen mode. |
| `game_launch_tip_23` | 提示：如果你使用的是 Mali GPU，请使用系统驱动。 | Tip: If you have a Mali GPU, please use System Drivers. |
| `game_launch_tip_24` | 提示：出现黑屏？尝试使用菜单中的“%s”选项检查驱动是否正常工作。 | Tip: Getting a blank screen? Try using the “%s” option in the menu to check if your drivers are working correctly. |
| `game_launch_tip_25` | 提示：如果在游戏中无法点击鼠标，请使用 Proton x86-64。 | Tip: Use Proton x86-64 if you can't click the mouse in games. |
